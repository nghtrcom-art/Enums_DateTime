# Uso de Enum e interface LocalDateTime.

**Algoritmo implementado com Enum e interface do tipo LocalDateTiime
, o program captura a hora e a data atual e assume que ela é a data
do evento, em seguida através de um méto na classe evento remarca a data.
Em seguinda, exibe na tela a data e hora de São Paulo junto com o fuso horario GMT.**
